## Question

## Setup

No saved KV is loaded by check_live_http.py. It reads only input/EOS fixtures and native output baselines. Each request performs live RNGD prefill, returns KV through the existing shared-memory protocol, and decodes on ATOM. Concurrency queues on a B1 lane; this is not hardware batch4.

Gemma/Qwen artifacts use context9216/k3; KONI uses its existing static context9216/k1 artifact with the #236 scheduler fix. Prefix and host caches disabled. This criterion does not establish answer quality (known shared wrong answers remain in #227/#233).
