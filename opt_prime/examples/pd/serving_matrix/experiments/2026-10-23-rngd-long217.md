## Question

Does Qwen3-0.6B extend to2K and8K RNGD full-prefix computation and32-token GPU/ATOM continuation? Full-prefix attention scales quadratically; successful handoff does not establish serving performance or overlap.

Checkpoint c1899de289a04d12100db370d81485cdf75e47ca. Fixed exact-length background/capital-question fixture from PR203. Three prefill repeats; first is cold, two warm. ## Results

2K: compile/init49.886s; cold587.666ms, warm216.594/222.390ms; repeat KV/logits exact. Export shape[28,8,2048,128] for each K/V.

GPU2K:32/32 continuation sequence matches native GPU,56 cache-slot readbacks exact. Relative RMS versus GPU BF16: K1.277%, V3.768%, logits2.503%. GPUFP32 comparison also matches the32-token continuation; relative RMS K0.904%, V2.694%, logits1.800%. Token agreement is not numerical equivalence.

ATOM2K: both importers read back56/56 slots; all31 decode logits exactly equal across importers. Both imported continuations differ from native ATOM at output index1 (native374 versus imported594), while the imported32-token sequence equals the GPU reference. This isolates a prefill/backend numerical difference rather than a difference between the two import implementations. It does not establish full model quality or tolerance bounds. Import timings550.266/427.187ms are single sequential samples, not an optimization benchmark.

ATOM diagnostic confirms a second-token greedy boundary: native token374 and594 logits both18.25, while imported KV yields594 at18.375 versus374 at18.25. Both importer top5 logits agree. This explains this fixture's branch but is not a general error bound. The diagnostic rerun overlaps8K compilation; its latency is not compared.

8K run in progress; no result claimed yet. Raw evidence: analysis/serving-matrix-201/rngd-*qwen3-06b-*.

Diagnostic command repeats the ATOM command with output rngd-atom-qwen3-06b-2048-diagnostic.json and the updated check_rngd_atom.py recording first-decode top5. FP32 GPU control repeats the GPU command with --dtype float32.

## Conclusion

2K RNGD transfer works mechanically and GPU continuation matches this fixture, but cross-backend ATOM/native equality fails. Keep numerical parity and full model/backend scope open. 8K capacity still requires actual-device evidence.
