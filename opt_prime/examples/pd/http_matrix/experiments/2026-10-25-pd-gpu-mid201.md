## Reproduction

Four decoder slots, BF16, context9216, paged KV/page64, local chunk256, caches off. Research RNGD producers use width8192/chip0 with the existing process-local fusion4/Mesh2 wrapper and streaming_factories adapters. This is not the vendor native LLM backend. Exact producer/HTTP/harness source hashes are in the summary. Frozen models and producer dependencies are the same as prior c16 streaming evidence. Before each arm, require no GPU compute process and no device-file holder for the selected RNGD; never terminate another workload.

Use benchmark201_native_http.py from commit052f84f experiments/evidence274 (custom HTTP profile), with direct serve_batched.py configs and existing producer wrapper/factories. The stream config adds --pd-prefill-stream-layers and uses the whole result as reference:

## Limits

Within-route and whole/stream parity do not establish native equivalence or general answer quality. This does not newly prove DMA or compute/copy overlap. Cache-on, ATOM intermediate c1/c4 coverage and supported engine export/cache integration remain separate. The four-model goal is not complete.

Cleanup verified after coordinator exit: GPU compute process query empty (exit0), selected RNGD device files have no holders (fuser exit1, no output). No unrelated process was terminated.
